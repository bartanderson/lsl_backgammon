# LSL Backgammon Project - Start Here

**Welcome back!** To ensure the agent is properly synchronized with the project state, please run the initialization workflow immediately.

## 🚀 Quick Start

Type the following command in the chat:

```
/initialize
```

## What This Does
1. **Checks Task Status**: Reads `task.md` to see where we left off.
2. **Verifies Tools**: Ensures safe editing tools are present.
3. **Checks Git**: Reviews current git status.
4. **Loads Rules**: Refreshes critical LSL coding rules.
